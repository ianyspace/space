这是 `content/template/` 的内容，**和 `AGENTS.md` 同级**。它不会被扫描成真正的文章：
只有 `content/blog/<目录名>/` 下的 `index.mdx` 才会发布。复制整个文件夹到 `content/blog/`
并改成**驼峰**形式的目录名（例如 `myArticle`），就可以开始写了。

完整规范见同级目录的 `AGENTS.md`，下面是常用写法的示例。

> 写作时记住三点：**简洁**（一段一件事，不写套话）、**清晰**（先结论后细节，层次分明）、
> **美观**（图文代码交替，别出现一屏纯文字）。发挥mdx作用动态交互。

## 代码块

围栏后**一定要写语言名**（`js`、`bash`、`json`…），否则整块不会有语法高亮。
想高亮某些行，把行号写在语言名后面（`{9}` 单行 / `{1,3-5}` 连续 / `{3-6, 8-10}` 多段）：

```js {2-4}
// 语言名后面写行号，这几行会带深蓝底 + 粉色左边框
const element = <h1 title="foo">Hello</h1>;
const container = document.getElementById('root');
ReactDOM.render(element, container);
```

数学公式直接写 LaTeX：行内 `$O(\log n)$`；行间公式让两个 `$$` 各自单独占一行（前后空一行）：

```md
$$
h \le \log n
$$
```

要显示普通的美元符号就写 `\$`。

## 使用组件

这篇文章如果需要可交互的小组件：

1. 在 `components/` 下新建 `MyWidget.js`，样式写在同目录的 `MyWidget.module.scss`，组件里
   `import styles from './MyWidget.module.scss'` 后用 `styles.xxx` 引用类名；
2. 在 `components/index.js` 里注册，key 就是正文要写的标签名：

   ```js
   import MyWidget from './MyWidget';

   export default {
       'my-widget': MyWidget,
   };
   ```

3. 正文里当普通 HTML 标签使用（小写 + 短横线）：

   ```html
   <my-widget kind="demo"></my-widget>
   ```

   写上这一行后**重启 `npm run dev`**，组件注册表是构建时生成的。

如果这个组件多篇文章都要用，就放到 `content/components/` 并在 `content/components/index.js`
里注册，写法完全一样。

## 几个约定

- 正文按 MDX 解析：`import` / `export` 这类语句不会执行，需要组件就写到 `components/` 里。
- 图片以文章目录下的 `images/` 为准。
- 组件样式写在该组件同目录的 `MyWidget.module.scss`。
